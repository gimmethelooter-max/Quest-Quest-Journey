# Quest Quest Journey

A gamified life-management and personal growth app with an RPG adventure aesthetic.

## Quick Start

```bash
npm install
npm run dev
```

Then open: **http://localhost:3000**

## Build for Production

```bash
npm run build
npm run preview
```

## Features

- 🎮 **RPG-Inspired Interface** - Modern adventure aesthetic with smooth animations
- 📋 **Quest System** - Daily, weekly, personal, and custom quests with difficulty levels
- ⭐ **XP & Levels** - Progression system with meaningful rewards
- 💰 **Coins & Rewards** - Earn and spend coins on custom rewards
- 🔄 **Habits & Routines** - Multi-step routines with progress tracking
- 🏆 **Achievements** - Unlock achievements as you progress
- 🗺️ **Journey Map** - Visual progression through life regions
- 📊 **Analytics** - Track progress by category and time
- 🌙 **Dark/Light/System Themes** - Full theme support
- 📱 **Mobile-First Design** - Optimized for all devices
- 📦 **PWA Ready** - Install as an app on mobile

## Tech Stack

- React 18 + TypeScript
- Vite
- Lucide React (icons)
- Local storage persistence
- Service Worker (PWA)

## Data Persistence

All data is stored in browser localStorage. Progress is automatically saved.

Connect this repo to Vercel or Netlify for automatic deployments.
